# Dicky News YouTube Admin

- `index.html`: panel kontrol dan ekspor JSON.
- `linkdickynews/index.html`: alur generator/verifikasi dari repository lama.
- `linklikecomment/index.html`: alur password atau Like & Comment dari repository lama.

Panel saat ini menyimpan draf di localStorage browser dan mengekspor JSON. Sinkronisasi langsung memerlukan backend terautentikasi; jangan menaruh token GitHub di frontend. Repository lama tidak dihapus.
